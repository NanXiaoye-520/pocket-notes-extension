# Pocket Notes

> 伪装成工作待办工具的私人写作工作台。

一个低调、不联网的浏览器扩展，用于在工作间隙收集灵感、记录素材、随手写作。

---

## 特性

- ⚡ **打开快，记录快** — 在网页右下角弹出一个小窗口，不打断浏览
- 🔒 **完全本地** — 所有数据保存在浏览器本地，不联网、不需要账号、不需要数据库
- 📝 **Markdown 导出** — 按「下班」一键导出 .md 文件，方便整理到 Obsidian
- 🎭 **伪装模式** — 点击标题切换，把写作内容伪装成工作任务列表
- 📂 **灵活分类** — 内置分类系统（好词、灵感、小说等），支持增删改
- 💾 **自动保存** — 停止输入约 2 秒自动保存，关闭浏览器也不丢数据
- 🖱️ **可拖动窗口** — 自动记住窗口位置，ESC 快速隐藏

---

## 安装

1. 克隆仓库
   ```
   git clone https://github.com/NanXiaoye-520/pocket-notes-extension.git
   ```

2. 打开 Chrome / Edge，进入扩展管理页面
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`

3. 开启「开发者模式」

4. 点击「加载已解压的扩展」，选择本仓库目录

---

## 使用

| 操作 | 方式 |
|------|------|
| 打开笔记 | 点击浏览器工具栏的 Pocket Notes 图标 |
| 添加摘录 | 选分类 → 输入 → 回车 |
| 编辑写作 | 切换到「写作」页 → 选分类 → 自由书写 |
| 导出 | 点击「下班」→ 自动下载 `YYYY-MM-DD.md` |
| 伪装模式 | 点击窗口标题「今日工作内容」切换 |
| 隐藏窗口 | 按 ESC |
| 管理分类 | 打开分类管理，增删改分类 |

  摘录  │  写作
────────┼──────────────────
分类:   │  分类:
[好词▼]│  [小说▼]

        │

        │
        │
────────┴──────────────────

- **摘录** — 收集好词、生词、诗句、对话、设定等碎片素材
- **写作** — 写小说正文、灵感、日记、大纲、世界观、人设等长文

## 技术

- Manifest V3（Chrome / Edge 兼容）
- 原生 JavaScript，无框架依赖
- Chrome Storage API 本地存储
- 零网络请求
